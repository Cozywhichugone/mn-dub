# Монгол дуу оруулга

Англи видеог монгол хоолойтой болгох автомат дамжлага. Өмнө нь гараар хийдэг
байсан дөрвөн алхмыг нэг товч болгосон.

```
видео → аудио салгах → Whisper → Claude орчуулга → Azure монгол хоолой → буцааж холих
```

Гаралт: монгол хоолойтой mp4, монгол .srt, англи .srt.

## Юу хэрэгтэй вэ

**ffmpeg** — [ffmpeg.org/download](https://ffmpeg.org/download.html)
macOS: `brew install ffmpeg` · Windows: `winget install ffmpeg` · Ubuntu: `sudo apt install ffmpeg`

**Гурван API түлхүүр:**

| Юунд | Хаанаас | Ойролцоо үнэ |
|---|---|---|
| Яриа таних | [platform.openai.com](https://platform.openai.com) | $0.006 / минут |
| Орчуулга | [console.anthropic.com](https://console.anthropic.com) | цаг тутам $0.10–0.30 |
| Монгол хоолой | [portal.azure.com](https://portal.azure.com) → Speech Services | сарын эхний 500,000 тэмдэгт үнэгүй |

Нэг цагийн видео дунджаар **$0.60–1.20** орчим болно. Azure-ийн үнэгүй хэмжээнд
7–8 цагийн яриа багтдаг тул ихэнх тохиолдолд зөвхөн эхний хоёрыг л төлнө.

## Суулгах

```bash
pip install -r requirements.txt
cp .env.example .env      # түлхүүрүүдээ бичнэ
python app.py
```

Дараа нь http://127.0.0.1:5000 хаягаар орно.

## Командын мөрөөр

```bash
python cli.py clip.ts -o ./out
python cli.py lecture.mp4 --voice male --volume 0.05 --burn-subs
```

## Тохиргоо

**Хоолой** — Азурын хоёр монгол neural хоолой: Есүй (эмэгтэй), Батаа (эрэгтэй).

**Эх дууны түвшин** — 0% бол эх дуу бүрэн алга болно. 10% нь хөгжим, дуу чимээг
мэдэгдэхүйц үлдээгээд ярианд саад болохгүй тэнцвэр. Баримтат кино, ярилцлагад
5–15% тохиромжтой.

**Ярианы үед автоматаар намсгах** — өргөн нэвтрүүлэгт хэрэглэдэг ducking.
Монгол хоолой орж ирэхэд эх дуу автоматаар сулраад, дуусмагц буцаад сэргэнэ.
Тогтмол түвшнээс хамаагүй байгалийн сонсогдоно.

**Нэр томьёоны жагсаалт** — техникийн үг, брэнд, хүний нэрийг тогтмол нэг
хэлбэрээр орчуулуулна:

```
machine learning = машин сургалт
neural network = нейрон сүлжээ
Anthropic = Антропик
```

## Хугацаанд багтаах асуудал

Монгол орчуулга англи эхээсээ ихэвчлэн 10–25% урт болдог. Тиймээс дамжлага
сегмент бүрийг эхлээд хэвийн хурдаар уншуулаад, дараагийн өгүүлбэр эхлэх хүртэлх
зайд багтахгүй байвал зөвхөн тэр сегментийг нь бага зэрэг хурдасгаж дахин
уншуулна. Хамгийн ихдээ 1.35 дахин — үүнээс цааш чихэнд эвгүй болдог тул хийхгүй.
Хэдэн өгүүлбэрийг хурдасгасныг ажил дуусахад мэдээлнэ.

Хэрэв хэт олон сегмент хурдассан бол орчуулгыг богиносгох нь дээр: `pipeline.py`
доторх `TRANSLATE_SYSTEM` заавар дээр "эх өгүүлбэрээс богино бай" гэсэн шаардлагыг
чангатгана.

## Локал Whisper

Интернэт хязгаартай, эсвэл OpenAI-д төлөхийг хүсэхгүй бол:

```bash
pip install faster-whisper
python cli.py video.mp4 --local-whisper
```

`large-v3` загвар анх удаа ~3GB татна. GPU байвал `.env` дотор
`WHISPER_DEVICE=cuda`, `WHISPER_COMPUTE=float16` гэж бичвэл хамаагүй хурдан болно.

## Форматын тухай

Rask зэрэг онлайн үйлчилгээ `.ts` (transport stream) файлыг татгалздаг. Энэ
дамжлага дотроо ffmpeg ашигладаг тул `.ts`, `.mts`, `.m2ts`, `.mkv`, `.avi`,
`.flv`, `.wmv` бүгдийг шууд уншина — урьдчилж хөрвүүлэх шаардлагагүй.

## Файлын бүтэц

```
pipeline.py          дамжлагын логик — тусад нь import хийж болно
app.py               Flask сервер ба API
cli.py               командын мөрийн хувилбар
templates/index.html интерфэйс
data/outputs/<id>/   гаралтууд
```

## Хязгаарлалт

Монгол neural TTS одоохондоо гадаад нэр, товчлол, техникийн нэр томьёог буруу
дуудах тохиолдол бий. Нэр томьёоны жагсаалтыг галигаар нь бичиж өгвөл ихэнхийг
нь засна. Гарсан видеог бүтнээр нь нэг сонсоод шалгахыг зөвлөе — үүсгэсэн
.srt файлыг засаад дахин уншуулж болно.
